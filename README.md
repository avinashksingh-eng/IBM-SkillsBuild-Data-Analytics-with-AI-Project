# IBM SkillsBuild Data Analytics with AI Project

Retail Business Intelligence & Data Analytics project completed for the IBM SkillsBuild Data Analytics with AI Academic Internship.

## Project Overview
This project presents a Business Intelligence (BI) and Data Analytics solution for Retail Sales. It implements a 5-level analytics hierarchy: KPIs, Trends, Drivers, Risks/Opportunities, and Actionable Recommendations.

## Technologies Used
- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Google Colab / Jupyter Notebook

## Files
- `Avinash_Retail_BI_Analytics.ipynb` — main analytics notebook
- `Avinash_ProjectReport.docx` — project report
- `requirements.txt` — Python dependencies

## Setup
```bash
pip install -r requirements.txt
```
Open the notebook in Google Colab or Jupyter Notebook and run the cells.

## Key Insights
- KPI summary covering total revenue, order count, and customer churn risk.
- Drivers covering top-performing product categories and regional sales.
- Action items identifying churn-prone customers for targeted retention campaigns.
